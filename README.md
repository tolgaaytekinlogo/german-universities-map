# Almanya Üniversite Gezi Rehberi

Bu proje, Almanya'daki üniversiteleri ziyaret etmek isteyenler için interaktif bir gezi rehberi uygulamasıdır.

## Özellikler

- 📍 İnteraktif harita görünümü
- 📅 Dinamik günlük plan kartları
- 🎯 Üniversite lokasyonları ve detayları
- 📱 Mobil uyumlu tasarım
- 🗺️ Leaflet harita entegrasyonu

## Dosyalar

- `seyahat_rehberi_ana.html` - Ana sayfa ve genel rehber
- `dinamik_gunluk_plan_kartlari.html` - Günlük plan ve harita görünümü

## Kullanım

Projeyi yerel olarak çalıştırmak için herhangi bir HTML dosyasını web tarayıcısında açabilirsiniz.

## Teknolojiler

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Leaflet.js (Harita)
- D3.js
- Vis-Timeline
